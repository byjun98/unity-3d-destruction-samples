# 에셋 제외 기준

이 프로젝트의 Git 저장소에는 직접 작성한 코드, 씬, 샘플용 머티리얼, 래퍼 프리팹만 포함합니다.

다음 항목은 커밋하지 않습니다.

- Unity `Library`, `Temp`, `Logs`, `UserSettings` 같은 로컬 생성 파일
- Asset Store에서 내려받은 원본 패키지와 import 결과물
- 대용량 텍스처, FBX, 사운드, VFX 원본
- 로컬 검증용 스크린샷과 개인 작업 메모

외부 에셋 참조가 끊긴 상태여도 구현 흐름을 확인할 수 있도록 코드와 데모 씬 중심으로 정리했습니다.
